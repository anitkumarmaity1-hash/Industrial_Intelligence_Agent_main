# Runtime dependencies for the API (Dockerfile) and frontend
# (frontend/Dockerfile) containers only.
#
# This is deliberately a SUBSET of requirements.txt, not a replacement for
# it. requirements.txt remains the source of truth for local development
# (it installs everything, including the Phase 1 PySpark pipeline and
# pytest). This file exists because:
#
#   - Nothing under app/ or frontend/ imports pyspark, pandas, pyarrow, or
#     pytest (verified: `grep -rn "^import\|^from" app | grep -E
#     "pandas|pyarrow|pyspark"` matches nothing but a .pyc). Those are
#     Phase 1 batch-job and test-suite dependencies.
#   - PySpark alone pulls in a JVM and ~300MB of jars. Installing it in an
#     image that only serves FastAPI/Streamlit requests would roughly
#     double image size and build time for code that never runs.
#
# If a future phase adds a runtime import of pandas/pyarrow to app/ or
# frontend/, add it back here explicitly — don't just copy requirements.txt
# over this file.
#
# Versions are pinned identically to requirements.txt. Keep them in sync
# by hand; there is no dependency-management tool wiring the two together.
